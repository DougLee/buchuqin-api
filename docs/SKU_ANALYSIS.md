# SKU经营分析（简化版）

入口：运营中心 → 校区日报之后的 SKU经营分析，路由 `/sku-analysis`。
接口：`GET /api/v1/admin/reports/sku-analysis`，参数 start/end/campusId/categoryId/keyword。
不新增表、字段或迁移。后端启动时沿用 RBAC registry 登记新菜单（写现有菜单表）；不自动授予普通角色。超管可见，其他账号由管理员按需授予该菜单。该权限包含成交、批发成本毛利、当前库存估值与当前结果导出，应只分配给相应经营数据可见人员。平台范围与校区范围按该接口自身授权判断。

## 口径

- 北京时间最近30个完整自然日，日期最大到昨日，单次最长366天。
- 按 paidAt 归期，仅当前 completed；after-sales/refunded 不计。无确认收货日期和退款追溯能力。
- 商品成交额 = 订单行成交价 × 零售数量，不扣优惠券，不含配送费；与订单页面目录价差毛利一致，与校区日报实付收入不同。
- 成本采用支付时 unitWholesaleCost 整分快照 × 数量；任一销售行成本缺失，该SKU毛利未知。零成本有效。不给历史成本做实时回填。
- 商品级正销售贡献；80%核心包含跨线商品，30%毛利分界，销售额中位数由全部正销售SKU计算。图表筛选仅影响明细。
- SKU为校区+Product.id，不跨校区按条码合并。官方库及总部仓不参与零售分析。
- 当前库存已在支付时扣减，可售参考=stock-lockedStock，不再减订单占用。负可售标异常。它不是实际盘点在库量，也不是历史库存快照。
- 库存估算金额=stock×当前wholesalePrice/unitsPerCase，按SKU舍入至分。仅供当前批发成本估值参考，不是财务库存价值。
- 缺失主档交易保留。无交易、无库存且非在售商品不纳入。无上市日期，不生成新品、积压和清仓判断。
- 单次读取采用只读 RepeatableRead 事务。导出为Excel可打开的UTF-8 BOM CSV，使用页面已加载且已筛选/排序的全量结果，包含口径、时间、筛选、规则版本及单位，并防止文本公式注入。
- 不持久化规则、结果快照，不承诺历史结果复现。规则版本 sku-simple-v1。

## 验证

后端：`pnpm exec jest --runInBand sku-analysis.spec.ts rbac.spec.ts`、`pnpm build`。
前端：`pnpm build`。浏览器使用独立虚构样本检查展示、象限筛选、负毛利详情；没有连接生产数据库。
真实数据覆盖率、容量性能与线上角色配置仍需在目标环境验收。当前使用有界日期查询并在服务端按SKU聚合，返回全量SKU以保证图表与导出一致；大型数据集需要另行压测。

已有前端会话回归测试的 current 401 clears the session 文案断言失败（期望“登录已失效”，实际透传“rejected”）；已在修改前 HEAD 的隔离副本复现，未修改该逻辑。
