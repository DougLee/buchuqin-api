## 发现与修复

| 问题 | 修复与复测 |

| API图片公网404 | admin nginx图片后缀正则抢占API。改 `location ^~ /api/v1/`，图片访问200；H5送达及报损凭证可访问。`d68d5b5`测试已部署。 |
| 接单倒计时误用支付期限 | 支付成功未更新timeoutAt。改为支付时刻+校区接单分钟；`e4efcd3`测试已部署，实际支付后相差3600000毫秒，75项回归通过。 |
