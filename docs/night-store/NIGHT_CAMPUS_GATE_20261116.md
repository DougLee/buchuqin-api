# 夜宵校区开通前置校验 · 2026-11-16

## 问题与处理

已绑定夜宵店的正式楼长，在 `nightEnabled=false` 时仍能切换工作台、备货、缴纳押金，只有开始营业才被拒绝。根因是切换资格和备货接口没有消费校区开关。

- 服务端业务上下文显式下发 `nightEnabled`，切换资格同时要求校区开通、正式楼长、绑定店铺。
- 配送端首页切换和“我的”经营分组共用该资格。经营页面加载前实时核验；未开通时返回白天，清除旧选择。资格接口失败不继续加载经营数据。
- 时段默认入口也要求正式楼长资格，避免实习楼长被默认时段反复导航进无权页面。
- 10个新增经营入口加校区守卫：工作台、商品池、商品管理、押金档位/缴纳、备货提交、开店/恢复、上下架及推荐。
- 新备货和押金支付意图在事务中再次检查开关，未开通不新增单据、不调用支付网关。
- **开通与营业时间分开**：已开通的校区可在白天提前备货；开始营业继续检查营业时段和白天闭店等原规则。
- 既有订单履约、备货取消/实收、盘点报损及账务查询保留API处理能力；后台不隐藏存量数据。关闭校区不会删除、冲销已有库存、押金或订单。
