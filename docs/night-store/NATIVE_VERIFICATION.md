# X05 微信原生能力：外部待验收（2%）

结论：`external-blocked`，不计通过。冻结权重2%，未改变原标准。当前可操作环境是本机H5与隔离业务API，没有在真实微信账户、收银台或iOS/Android设备执行这些检查；MP编译成功不能替代运行验收。

本轮外部微信支付/退款为明确模拟，已证明内部订单、库存、券、额度和佣金链；H5原生文件选择器实际上传也已通过。不能将它们描述为微信真实登录、支付、消息、相机通过。

执行前确认使用**测试API、测试数据库、获授权的测试AppID及商户**，不能切换生产验证。导入两端 `dist/build/mp-weixin-buchuqin`，按 TEST_DEPLOYMENT.md 显式构建测试地址。
