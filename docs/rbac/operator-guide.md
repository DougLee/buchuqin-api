# 权限管理操作说明

本说明对应本次本地改造版本。是否可交付以 implementation-status.md 的验收状态为准。

## 一个账号管理多个校区

角色定义岗位能做的事情，账号授权决定在哪个校区生效。例如：

| 账号授权 | A 校区生效 | B 校区生效 |
|---|---|---|
| 运营角色 → A；财务角色 → B | 运营能力 | 财务能力 |
| 运营角色 → A、B | 运营能力 | 运营能力 |
| 运营角色 → A；财务角色 → A | 运营和财务能力并集 | 无权限 |

顶部切换运营校区后重新取得该校区的权限和数据。多选 A/B 不代表自动获得未来新建的 C 校区；只有显式的平台范围授权覆盖全部校区。平台范围按每个操作单独计算，一个平台只读角色不会把另一个校区角色的写权限扩大到全平台。

超级管理员必须使用平台范围，由系统保护，不能作为校区范围角色授予。校区管理员不能自行配置菜单、角色或账号授权；即使在普通角色中勾选了这些管理接口，后端仍会拒绝。

## 配置角色与账号

1. 超级管理员进入“角色管理”，新建角色，填写编码、名称和备注。编码创建后保持稳定。
2. 在功能树中搜索并选择功能。勾目录/父菜单会联动全部子节点；只选部分子节点时父节点显示半选；“仅查看”选择菜单查看能力而不选择子操作。保存空树表示该角色没有功能权限。
3. 菜单/按钮节点可以包含多个接口权限，名称只是说明。使用自定义节点时，先在“菜单管理”核对实际勾选的接口。例如只授予“商品改价”不授予普通编辑或上下架。
4. 进入“账号管理”，新建账号或编辑账号。添加授权行，选择角色和范围；校区范围可多选（原生列表支持 Cmd/Ctrl 点选），同一角色可作用于多个校区，也可添加不同角色的授权行。
5. “平台（跨校区）”是明确授权，不是省略校区的快捷方式。只给确实承担平台职责的岗位。
6. 保存时资料、密码重置、状态、授权及审计同事务提交；任一部分校验失败不会留下部分修改。修改授权/停用/重置密码会使旧会话失效，账号需重新登录。
7. 用“预览权限”核对该账号当前校区的有效权限和全部绑定。最后用目标账号登录并切换校区验收。

停用角色使所有绑定此角色的账号失去该角色能力，其他有效角色仍生效。删除被账号引用的角色前必须撤销引用。系统不允许停用、删除或撤销最后一个有效超级管理员。

## 菜单、路由与按钮

- 目录负责组织导航；菜单映射页面；按钮节点承载细分操作权限，不作为导航入口。
- 名称、图标、排序、父级、显示开关均保存在数据库。移动/编辑已有节点后，服务重启不会覆盖合法配置。
- 页面组件只能选择已登记的页面。新建菜单可以复用已有页面，不能通过填写文件路径生成新业务页面。
- 路由路径在菜单之间不能重复；不能把节点移动到自己的后代下面；有子节点时不能改成按钮。
- 接口权限从可搜索的目录多选。普通编辑、改价、上下架、财务确认/打款和证件访问是不同能力。
- “在导航中显示”关闭，只隐藏侧栏入口。账号仍有这个菜单授权时可通过直达路径访问；要彻底撤权，必须移除角色对应节点或停用角色。
- 页面缓存只保存当前授权上下文的页面状态。切换账号、校区或权限变化时清理旧状态，避免旧页面数据继续展示。
- 外链页面要求 HTTPS，嵌入第三方页面还受对方的 iframe 策略限制。配置外链不会把本站 token 传给对方。
- 配置保存后刷新权限数据；当前版本也在切页、窗口重新聚焦及周期刷新时更新。后端每次请求仍实时验证会话和权限版本。

## 商品细分权限示例

只改价：商品菜单 + 商品改价。详情中仅价格输入可修改，不显示创建、导入和上下架动作。

只上下架：商品菜单 + 商品上下架。可行内/批量上下架，无须授予普通编辑。

普通编辑：商品菜单 + 商品编辑。若还需要改价或上下架，分别勾选对应能力。分类/库位候选需要相应查看接口权限；没有候选权限时不会请求它们。

## 会话策略

默认允许多处登录。配置 `ADMIN_SINGLE_SESSION=true` 后，新一次成功登录会使该账号以前的令牌失效。所有实例应使用相同配置。这里指同账号单会话，不是第三方统一身份登录。

自助改密后退出当前会话，使用新密码重新登录。撤权或停用后，旧令牌不能通过切换校区或自助改密换回有效会话。

## 与 breeding 的适配差异

- 保留 Vue/Nest/Prisma 和现有 REST 接口；权限严格区分 HTTP 方法与路径，不使用字符串子串匹配。
- 数据范围采用已确认的“账号角色绑定选择校区”，不照搬角色部门树。角色与校区配对计算，防止能力跨校区交叉放大。
- 保留 bcrypt、sessionVersion、RbacState 与事务审计；不移植 MD5、默认密码或硬编码用户 ID 超管。
- 页面组件使用显式登记目录，不允许数据库路径加载任意本地文件。
- 内置节点可修改配置但保留删除保护，避免移除系统基础入口；超级管理员角色不可修改/删除。
- 系统管理配置只由超级管理员完成；原有显式平台只读账号可以读取已授权账号信息，不能配置角色和授权。

迁移和故障回滚见 migration-guide.md。真实部署前需用部署库副本做逐账号范围对照，合成样本不能代替实际数据验收。


## 图片与校区筛选的细分权限

后台图片上传按用途复用业务写权限：Banner/详情图要求 Banner 新增或编辑，商品图要求商品新增或编辑，分类图要求分类新增或编辑，群码要求群码维护，转盘图要求转盘维护。单独改价、上下架或只读权限不能上传商品图。身份证照片只接受独立证件写权限，使用私有 ACL。通用 uploads 目录要求至少一种公开素材写权限。已有小程序普通用户的公开上传流程保留。

库存账号不需要额外授予商品管理或校区管理权限：库存选择器读取库存数据，校区筛选读取当前账号可用的校区名称。平台账号先在筛选中选择目标仓库，再执行入库；未选仓库的入库请求会拒绝。筛选名称列表不包含校区计数和管理配置，也不改变账号的校区切换授权。

运营备注不进入通用审计快照，只记录是否存在备注；历史招募审计读取时也会屏蔽备注、证件图片并掩码证件号。

## 审计与价格字段边界

普通“审计日志”只展示已授权范围内的业务审计，不包含 rbac.* 授权快照。角色、账号、菜单和授权变更在独立“权限审计”中查看，该接口要求显式平台能力；避免从业务日志读出其他校区的账号绑定。

本轮复刻保留现有商品与订单的成本、批发价、毛利业务口径，没有新增独立的“读取成本”权限。商品列表中的 costPrice 不能因为前端某个表格隐藏而视为接口保密字段；可访问对应商品记录的账号仍可能从 API 读取该值。官方目录属于共享资料，本校订单的成本快照用于已有毛利展示；跨校区采购金额与批次毛利汇总仅平台范围可见。
